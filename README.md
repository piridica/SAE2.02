# Affichage d'accueil
Liste des fichiers.txt stockés dans le dossier input au format : 
x. nom du fichier de l'oeuvre
  x représente l'indice du fichier txt à insérer dans la console afin que le programme le sélectionne et le compresse.
  
  Il est possible pour l'utilisateur de sélectionner une plage de fichiers à compresser, au format d'un tuple, donc (x,y), x étant l'indice de début, et y l'indice final du fichier à compresser.
  
  Il est également possible d'insérer une liste discontinue si l'utilisateur souhaite compresser des fichiers précis sans en compresser certains, au format [x,y,z]
  
  Si l'utilisateur n'insère rien, alors le programme compressera tous les fichiers présents dans ce dossier par défaut.
